# 🏷️ Floating Label Form

A simple beginner-level form UI project focused on creating animated floating labels using HTML and CSS.

This is a small practice project before building a complete modern form with advanced features and a full form structure.

## 🪼 Features

- Floating labels
- Focus animation
- Username, Password & Email fields
- Responsive layout
- CSS theme variables
- Simple hover effect

## 🛠️ Built With

- HTML5
- CSS3

## 📌 Note

This project is only a small practice component.
A complete modern form project with more advanced features will be built separately.
