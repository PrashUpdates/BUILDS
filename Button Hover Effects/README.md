# ⏹️ Button Hover Effects

A collection of modern button hover animations built using pure HTML and CSS. This project demonstrates smooth fill effects, hover transitions, pseudo-elements (`::before`), and creative border-radius animations without using JavaScript.

## 🎐 Features

- Pure HTML & CSS
- Smooth Hover Animations
- Top Fill Effect
- Bottom Empty Effect
- CSS Variables
- Pseudo-element Animations
- Responsive Layout
- Beginner Friendly

## 🛠️ Technologies Used

- HTML5
- CSS3
