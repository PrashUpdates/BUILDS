# 💬 Feedback Card

A modern feedback card UI built using pure HTML and CSS. This beginner-friendly project focuses on clean layouts, flexbox, hover effects, and responsive card design.

## ✨ Features

- 🎨 Modern Card Design
- 👤 User Profile Section
- 🟢 Online Status Indicator
- 🔁 Retry Button
- ✅ Score & Feedback Section
- 💻 Pure HTML & CSS

## 🛠️ Technologies Used

- 🌐 HTML5
- 🎨 CSS3
