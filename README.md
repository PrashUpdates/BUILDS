## 📌 Overview

This repository acts as a centralized workspace for all my web projects, custom CSS components, and JavaScript logic implementations. Every project is completely **standalone** and organized in its own folder to keep the codebase clean and modular.

> [!NOTE]
> Every folder inside this repository is self-contained. You can directly grab the code from any folder without configuring complex build tools or dependencies.
