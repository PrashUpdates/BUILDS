# 📦 CSS Box

A collection of modern, clean, and reusable CSS UI components built to speed up frontend development.

--

## 🚀 About This Repository

This repository serves as a central vault for various UI elements, components, and layout patterns. 

Each component is placed in its **own folder** and includes:
- `index.html` (Markup)
- `style.css` (Styling)
- `README.md` (Quick preview/guide for that component)
