## ✨ Features

- ♾️ Infinite Seamless Scroll
- ⏸️ Pause Animation on Hover
- 🔄 Bi-directional Scroll Support (Left to Right / Right to Left)
- 🖼️ Dynamic Content & Image Support
- 📱 Responsive Layout


## 🚀 Built With

- HTML5
- CSS3 (Pure CSS Animations)
